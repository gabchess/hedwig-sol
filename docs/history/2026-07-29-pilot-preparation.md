# Seven-day pilot preparation

Historical record, superseded 2026-09-06. This is not the current offer. See [agent access proof](../agent-access/proof-offer.md).

Status: offer published; signed pilot open

Date: 2026-07-29

## Decision

Hedwig will validate its shared-authorization model through one bounded,
seven-day pilot with a qualified Anchor team. The selected path must change
state across two related programs through direct calls or CPI.

The pilot starts from the team's current authorization behavior. It produces a
manual before-and-after authority map, migration and rollback steps, a custody
dry run, and an explicit merge, revise, or reject decision.

## Published offer

The [pilot program](2026-07-shared-authorization-pilot.md) records the scope, team requirements,
current product limits, and decision criteria. The offer keeps actor
authentication inside each consuming program and uses Hedwig only as the shared
membership store.

## Claim boundary

Publishing the offer changed documentation only. It did not change program
code, deployed bytes, account layouts, upgrade authority, or any trust boundary.

No signed pilot, design partner, customer, revenue, production use, or external
adoption has been verified. The builder-owned reference consumer remains
technical integration evidence.

## Next gate

The next public evidence is a signed scope from one qualified team for one
two-program path. Product expansion remains gated on the result of that pilot.
